# CDTV 漫剧自动化客户端（comoc-drama-client）

[English](README.en.md) | 简体中文

一个使用 Vue 3、pywebview、Python 和 Playwright 构建的本地桌面应用，面向 AI 漫剧制作流程自动化。将项目管理、素材整理、分镜编辑、视频生成与账号调度整合到统一工作区，通过 OriginalDoubao 浏览器自动化减少重复配置与提交工作。**项目数据与素材保存在本机，无需部署后端、无需 Java、客户端免注册登录；OriginalDoubao 视频生成需单独登录对应账号。**

## 功能概览

- **项目管理**：项目与章节管理，Markdown 剧本编辑，实时保存与标题锚点导航。
- **素材库**：提示词、人物 / 场景 / 道具 / 白模 / 音频素材的分类管理与本地预览。
- **OriginalDoubao 视频生成**：本地选图、提示词、画面比例与时长设置，任务进度与结果回传；需登录 OriginalDoubao 账号。
- **多账号管理**：每个 OriginalDoubao 账号拥有独立的浏览器 Profile 与登录态；账号列表保存在本机。
- **额度与调度**：对用户合法持有的账号记录每日视频额度，运行中加锁，任务结束自动释放，避免重复提交；不用于绕过平台额度或风控。
- **链接转换与视频处理**：保留现有分享链接转换、视频下载与水印处理功能。使用前应核实素材授权、平台许可及内容标识要求。

## 快速上手

1. **启动客户端**：已有打包版本时运行 `CDTV.exe`；源码运行按 [开发指南](docs/DEVELOPMENT.md) 安装依赖并启动。
2. **建立项目**：创建项目和章节，编辑 Markdown 剧本，添加本地素材。
3. **准备分镜**：建立视频创作任务，逐条填写分镜，或按下方说明导入创作数据 JSON。
4. **配置 OriginalDoubao 账号**：在设置中心添加账号，打开该账号的浏览器并手动登录。网页自动化需要应用目录下的 `runtime/chrome-win64/chrome.exe`。
5. **生成与预览**：为分镜选择图片、填写视频描述和支持的参数，提交后查看任务进度与生成结果。

客户端本身免登录，OriginalDoubao 网页生成需要单独登录 OriginalDoubao。只做本地项目编辑和素材管理时，不需要配置模型 API。

## 本地存储与 AI 能力边界

项目数据与上传文件默认保存在本机：

- **内置本地存储服务**：`local_storage.py` 使用标准库 `sqlite3` + `http.server`，启动时在 `127.0.0.1:18081` 提供数据与文件存储接口。
- **单机账号**：应用内使用本地用户，无需注册或登录。

默认数据库为 `data/storage/storage.db`（SQLite），上传文件位于 `data/storage/files/`。设置中心可修改存储目录；生成视频默认写入 `output/`。备份时先关闭客户端，再复制整个实际存储目录。

> 当前实现：`/ai/image` 支持 OpenAI 兼容的图片生成和参考图编辑；`/ai/audio` 支持 MiniMax 音色设计及试听音频；`/ai/video` 支持 Seedance 任务提交、查询和成片保存；`/ai/chat` 支持 Chat Completions 与完整 `/messages` 地址的非流式文本转发。接口读取设置中心已启用模型的 API 地址、API Key 和模型名，生成的媒体保存到本地。图片地址可填写服务根地址、带 `/v1` 的地址或完整 `/images/generations` 地址；音频和视频建议按下表示例填写完整接口地址。OriginalDoubao 浏览器自动化是独立通路，需要联网及有效登录态。MiniMax 音色试听不等同于完整对白配音或视频口型同步。

## AI 创作数据与第三方 JSON 导入

项目内置 `SKILL/` 目录，是一套面向 AI 分镜创作的**参考规范**（`SKILL.md` + `references/` 数据模型与规则文档），可作为把剧本转换成结构化、可校验的漫剧分镜数据的参照。

`SKILL/test-json/` 下附带一份完整的示例创作数据（[`末日重生-完整数据.json`](SKILL/test-json/末日重生-完整数据.json)），可直接用于本项目的创作数据导入，用来验证导入流程与字段结构：包含 `style`（风格与画面提示词）、`consistency`（人物 / 场景 / 道具 / 音频）以及 18 条 `shots` 分镜。需要一份可导入样例时，可从该文件开始。

外部工具（其他 AI 分镜工具、表格导出脚本等）生成的创作数据 JSON，应先检查字段结构：已符合客户端支持的资产与分镜字段时可导入，不一致时再做格式转换。转换时可以参照 [`SKILL/references/json-schema.md`](SKILL/references/json-schema.md) 的数据结构，把来源字段映射过来（标题、画面描述、时长、角色 / 场景 / 道具 / 配音等）。

导入只做**格式转换**：不改变来源已确定的剧情、对白与镜头顺序，缺失信息以用户提供的事实为准。`SKILL/` 是可供参考的规范与示例，并非必须严格遵守的流程——你也可以按自己的方式转换，只要最终符合本项目的 JSON 结构即可。创作流程见 [`SKILL/SKILL.md`](SKILL/SKILL.md)，实际导入字段与校验边界见 [客户端接入说明](SKILL/references/client-integration.md)。本仓库只包含参考规范，未随附外部 `duanju` 编译和校验脚本；导入成功也不表示完整 H3 生成配置已保留。

## 多账号管理

这里的“多账号”指**OriginalDoubao 账号**：每个 OriginalDoubao 账号独立登录 OriginalDoubao 网页、独立浏览器 Profile、独立每日生成额度，客户端分别记录其额度并调度任务。

1. 点击右上角“添加 OriginalDoubao 账号”，输入便于识别的名称。
2. 选中账号，点击“打开 OriginalDoubao 并登录此账号”，在弹出的浏览器中手动登录后关闭窗口。
3. 重复以上步骤添加更多账号。

每个账号的登录状态独立保存在 `data/accounts/<账号ID>/profile`，浏览器 Profile 文件保存在本机；访问 OriginalDoubao 时，浏览器会使用该账号的登录凭据。

客户端为每个账号维护本地每日视频额度（默认 3，是客户端设置，不代表平台实际额度）：账号管理中显示“今日剩余/每日上限”，生成成功后自动扣减，次日重新计数；生成中账号会进入“运行中”锁定，任务结束自动释放，也可在设置中心手动释放或标记额度。

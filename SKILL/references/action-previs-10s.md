# 通用打戏动作动力学与 10 秒 PREVIS 导演系统

用于现代写实、武侠仙侠、3D 国漫、二次元和赛博动作的 10 秒战斗素材。先保证动作因果、空间连续和人物状态，再增加高燃运镜与特效。不得为了满足节奏指标凭空增加招式、伤害或胜负。

## 1. 动作强度分档

| 档位 | 适用 | 开场 | 对招 | 反馈 | 镜尾 |
| --- | --- | --- | --- | --- | --- |
| R1 写实克制 | 写实格斗、暗杀、追逐、喜剧、儿童向 | 1.5 秒内进入威胁或接触 | 可选 | 真实重心与受力优先 | 可收势或悬念 |
| R2 商业高燃（默认） | 多数短剧、漫剧打戏 | 原生开场优先在 0.8 秒内发生攻防；连续镜头直接继承上一镜动作 | 至少一段清晰攻防链 | 必须交代接触、闪避或破防结果 | 冲击结果或强 Hook |
| R3 玄幻大招 | 仙侠、二次元、特效终局 | 快速展示对立能量或动作关系 | 必须有实体动作支撑 | 动作、环境与特效共同反馈 | 高潮或灾变结果定格 |

“开场硬撞”只适用于一条战斗序列的原生开场。若本素材承接上一素材，00:00 必须严格使用 `continuity.state_in`，不得为了硬撞重置站位或跳过桥接动作。

## 2. 10 秒节奏骨架

先按动作量分配时间，再填写时间码。`acts[]` 按有意义的动作节拍划分，通常 4–7 段，不按每秒机械切割。

### R1 建议

- 0.0–1.5 秒：威胁建立、观察或首次接触。
- 1.5–4.0 秒：第一轮攻防。
- 4.0–7.0 秒：位置变化、擒拿、追逐或失衡。
- 7.0–9.0 秒：结果落地。
- 9.0–10.0 秒：收势或悬念交接。

### R2 建议

- 0.0–0.8 秒：冲突钩子或承接中的即时攻防。
- 0.8–3.0 秒：第一轮快速对招，动作线清楚。
- 3.0–4.0 秒：短暂停顿、读招或受力呼吸。
- 4.0–7.0 秒：第二轮压制与防守崩解。
- 7.0–9.5 秒：反转、破绽抓取或重击结果。
- 9.5–10.0 秒：保留冲击峰值或强方向性 Hook；不得凭空重置姿态。

### R3 建议

- 0.0–0.7 秒：对立招式或能量关系显现。
- 0.7–2.5 秒：实体攻防建立，禁止只让光效代替动作。
- 2.5–3.5 秒：短呼吸或局势判断。
- 3.5–6.5 秒：升级连招与空间位移。
- 6.5–8.0 秒：终结技蓄力，必须有身体和环境反应。
- 8.0–10.0 秒：碰撞、结果和可继承的高潮状态。

以上为节奏模板，不是固定时间表。复杂腾空、翻越、摔投和多人换位应增加时长；短刺、寸劲和单次格挡可缩短。一个时间段只承担一个主要动作目的。

## 3. 10 秒完播潜力自检

启发式评分：`0.20×开局吸引力 + 0.30×节奏呼吸 + 0.25×镜头可读与变化 + 0.25×情绪拐点`。它只用于创作自检，不代表平台完播率预测。

- 开局：R2/R3 原生开场在 0.8 秒内呈现威胁、接触或明确动作问题；连续镜头以无缝承接优先。
- 呼吸：快慢交替，同一节奏通常不超过 3 秒，但完整动作不得为了换节奏被切断。
- 镜头：10 秒战斗通常使用4–7个动作节拍，但默认是一条连续摄影机路径，不等于4–7次剪辑。摄影机可在同一轴线内由中景跟拍自然过渡到近景接触点，再拉回全景交代结果；只有用户明确要求剪辑式蒙太奇时才硬切。
- 拐点：优先在 5.5–8.5 秒出现破防、反制、失位或环境变化。
- 镜尾：R2/R3 保留在冲击结果、严重失衡、招式将发未发或明确悬念上；终局镜头必须额外交代胜负和状态，不能只有爆炸。

### 有效动作密度

- R2/R3 的有效攻防、追击、闪避、受力或带伤移动按校验契约至少覆盖素材时长80%；可按剧情提高密度，不能为了凑时长添加原文没有的攻防。纯展示与收势按动作需要分配。
- 一条 10 秒素材至少包含两次状态变化：第一轮攻击改变防守状态，第二轮反制、追压或失衡改变位置或伤势。
- 受力反馈必须与退步、卸力、反击或再次架剑同步发生，禁止先打完再用 3–5 秒分别展示“力量传递、结果、收势”。
- 镜尾 Hook 优先使用已经启动的剑线、步法、失衡或环境危险，不用纯眼神和衣摆填充战斗时长。

## 4. 关键重击的 11 环动力链

关键重击按以下链条推导；连接招只需写清起点、轨迹、应对、结果和继承状态，不得把 11 环逐字堆入每一招。

1. 攻击意图：锁定目标与战术目的。
2. 起手蓄力：架势、呼吸、肌肉张力。
3. 重心位移：前后、高低和支撑面变化。
4. 足部驱动：蹬地、踏步或腾空来源。
5. 腰胯转矩：力量如何被放大。
6. 脊柱传导：力量传至肩肘腕或髋膝踝。
7. 攻击轨迹：直刺、横扫、下砸或螺旋等明确几何路径。
8. 接触或落空点：击中哪里，或从哪里擦过。
9. 受力反馈：姿态变形、武器震颤、滑步、离地或环境反馈。
10. 收招惯性：攻击方如何卸力和稳定。
11. 下一击继承：结束位置怎样直接成为下一招起点。

受力表现服从 [风格锚点](style-anchor.md) 与项目 `style.negative_prompt`，本文件不单独授权血迹或其他伤势尺度。非血腥项目可用衣物破损、呼吸变化、姿态受限与非开放性受力反应逐镜累积，不要求人物每次接触后恢复完好。

## 5. 镜头五维规格

H3 目标按 [运镜规划](camera-h3.md) 生成 camera_motion 并派生 camera，下述五维格式仅作为其他目标的写作辅助。

其他目标的战斗 `acts[].camera` 使用：`[景别]·[水平面方位]·[机位高度/俯仰角]·[运镜]·[跟随目标]`。

示例：`中景·45°斜侧·平视·横移跟拍·跟随顾长渊剑鞘扫向沈青璃腰侧的完整轨迹`。

- 大幅腾空、长距离突进、摔投和轻功换位优先使用中景或全景。
- 短桥、寸劲、擒拿和武器接触点可用中近景、近景或特写。
- 中景/全景优先 30°–60°斜角建立纵深；90°侧拍仅在需要清楚展示轨迹或近景接触时短暂使用，不作为长时间默认机位。
- 16:9 利用横向纵深和对角线推进；9:16 利用垂直落差和冲镜动作。
- 默认连续单镜头；景别、角度和机位变化必须通过可执行的推、拉、横移、升降或有限环绕连续完成。必须换镜时，切点落在动作节点、遮挡点或受力点上，不能为了“丰富”切断空间关系。

## 6. 近身快速对招

R2/R3 可安排 1.5–2.5 秒近身对招，但不是每条素材强制出现。禁止写“快速连击”或“每秒打 N 拳”，应列出可读的 3–4 个动作及应对，例如：

`左掌拍开剑腕 → 对手沉肘封中线 → 右肩贴入破架 → 对手碎步后撤卸力`。

常用节奏：三轻一重、封—破—杀、左右交替加速。每一击都必须从上一击结束姿态自然起手。

### 技法多样性

- 双人兵器战不能退化成连续挥砍。除纯粹试探镜头外，每条 R2/R3 素材通常组合至少三类可见技法：兵器不同部位用法、拳掌肘肩膝腿、擒拿锁控、身法步法、环境借力、能量技法。
- 剑类兵器应区分剑尖刺、剑刃切、剑脊压、剑格锁、剑柄撞、剑鞘格挡；不得全部写成“挥剑”。
- 徒手动作必须来自合理距离和空闲肢体。角色双手握剑时不能无解释同时出掌；发生换手、松手或擒腕时同步更新持物状态。
- 特效只强化已经发生的身体与兵器动作，不能代替近身攻防。

## 7. 防守与闪避

- 防守破坏遵循：完整防守 → 防线崩开 → 0.3–1 秒过渡失衡 → 恢复、继续溃败或被命中。
- 关键闪避优先采用轮廓清楚的下潜、后仰、侧跨、翻转或滑步，并交代新位置。
- 小幅偏头、侧身和微步不是绝对禁止；只有当角色能力、距离和镜头景别足以让观众看清险距时才能使用。
- 被破防者不得下一帧原地满状态复原。把失衡方向、受影响肢体、呼吸、武器状态和落脚点写入 `state_out`。

## 8. 碰撞、空气与特效

- 轻击：短促剑风或空气波纹，发丝衣摆轻微受风，结果以偏转、失位或微震表达。
- 重击：明确接触点、支撑脚滑动、武器震颤、尘土碎石和环形气浪；反馈强度服从角色力量。
- 终结技：能量先聚拢，再沿身体与武器传导，最后在明确接触点爆散；必须展示结果，不用特效遮住人物动作。

角色特效固定四项：起源点、流动形态、终点爆散、余韵残留。颜色服从人物资产主色，跨镜不得无理由变化。

10 秒 R3 特效分配建议：0–2 秒短促显色，2–7 秒保持动作可读、只在关键接触点出现反馈，7–10 秒完成聚拢—增长—爆发—结果。不得全程用高亮粒子覆盖身体和武器轨迹。

## 9. 与连续性字段的绑定

- `continuity.state_in` 决定 00:00 的站位、朝向、姿态、持物、体力、伤势和场景破坏。
- 每个攻防节拍写清 `combat.setup/intent/action/response/outcome/recovery`。
- `performance` 负责预备、主动作、惯性、稳定和次级运动。
- `acts[]` 使用 4–7 个自然时间段，时间与动作量匹配。
- `director_timeline[]` 与 `acts[]` 使用相同时间边界，为每段补充空间、声音和交接状态；不得另造一套逐秒时间线。
- `state_out` 必须记录本素材真实结果，并与下一素材 `state_in` 逐键相等。
- 角色退出、倒地、失去行动力、死亡、消散或被封印时填写 `exit_state`，且可见结果必须出现在画面中。

## 10. 生成前检查

1. 当前属于 R1、R2 还是 R3？
2. 这是战斗原生开场还是连续素材？
3. 10 秒内只包含模型能够完成的动作量吗？
4. 每段时间是否对应一个清晰动作目的？
5. 攻击轨迹、防守反应、结果和收势是否闭合？
6. 运镜是否看得清，而不是只追求变化？
7. 体力、伤势、武器和场景破坏是否进入 `state_out`？
8. 镜尾是高潮、结果还是 Hook？下一镜能否从该姿态直接开始？

## 11. action_design 数据结构

战斗素材在切分 `acts[]` 前先建立：

```json
{
  "action_design": {
    "intensity": "R2",
    "combat_styles": {
      "CHAR-001": "低重心、重兵器直线压迫、收势较慢",
      "CHAR-002": "斜线步法、借力偏转、短停后加速"
    },
    "technique_mix": [
      "剑柄撞腕",
      "肩撞",
      "擒腕",
      "侧跨步"
    ],
    "exchanges": [
      {
        "time": "00:00-00:04.5",
        "initiative": "CHAR-001",
        "attack": "具体第一轮攻击",
        "response": "具体应对",
        "outcome": "第一轮状态变化",
        "state_delta": {
          "CHAR-002.balance": "broken"
        }
      },
      {
        "time": "00:04.5-00:09.3",
        "initiative": "CHAR-002",
        "attack": "基于失衡状态发起的反制",
        "response": "对手带着前一轮惯性应对",
        "outcome": "第二轮位置或伤势变化",
        "state_delta": {
          "CHAR-001.location": "东侧护栏前"
        }
      }
    ],
    "active_combat_s": 9.3
  }
}
```

- R1 至少一轮完整攻防；R2/R3 至少两轮，后一轮必须读取前一轮 `state_delta`，不能彼此独立。
- `technique_mix` 记录实际会出现在画面中的技法，不列空泛类别。
- R2/R3 的 `active_combat_s` 通常不少于素材时长的 80%；静止结果和纯收势合计通常不超过 1 秒。
- `combat_styles` 是角色级动作语法。两人的招式互换后若仍无违和，说明风格定义不合格。

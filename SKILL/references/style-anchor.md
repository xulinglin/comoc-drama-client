# 风格锚点模板（第一步）

为一部短剧建立全局一致的 AI 视频生成风格基准。**默认先锁定高精度3D写实国漫，再填其余维度**，最后压缩出锚点词根。真人写实不作为自动路线。

## 零、视觉路线判断（必选，先于一切）

- 视觉路线：高精度3D写实国漫（默认；真人写实仅在用户明确要求真人实拍时允许）
- 判断依据：______（默认使用3D的一致性、材质和角色可控性；如用户明确指定真人再记录例外）

判断规则（按优先级）：

1. **默认路线**：没有用户明确的真人实拍要求时，都市、家庭、职场、复仇、末日、玄幻、仙侠、异世界和奇幻生物都使用高精度3D写实国漫。
2. **用户明确要求优先**：只有用户明确写出“真人实拍、真人演员、真人写实摄影”等要求时，才记录真人路线；不得根据“现实题材”自行切换真人。
3. **一致性风险**：跨集一致性、角色可控性和复杂服装要求优先使用3D；默认不因题材现实而降低3D路线。

路线互斥规则（中文负向提示词必须使用明确的否定句式，置于第一优先位）：

- **默认3D路线**：词根必须含 `高精度3D写实国漫`、`高精度3D角色建模` 或同等明确的3D国漫媒介词；负向段必须写：`不要出现真人实拍；不要出现真人照片；不要出现真人实景；不要出现摄影棚真人肖像；不要出现写实摄影照片效果。` 这些词只排除实拍/摄影媒介；不得禁止真实皮肤细节、皮肤纹理、真实材质或写实建模，以免降低高精度PBR角色质量。
- **真人路线（仅限用户明确要求）**：词根含 `真人实拍`；负向段才写：`不要出现3D渲染；不要出现3D游戏CG；不要出现卡通；不要出现动漫；不要出现2D动画；不要出现CG质感；不要出现低模效果。` 用户未明确要求真人时禁止使用这一组路线。

> 不要只写 `真人实拍、真人照片……`，也不要把多个排除项合并在同一个“不要出现”后面。部分模型可能只把否定关系绑定到第一项。每个排除项都必须独立重复“不要出现……”或“禁止出现……”，并用分号隔开。

- 音效偏好：______（只定义整体质感，如：克制的环境声、清晰的物理碰撞声；不得预设无剧情来源的心跳声、提示声或拟声）
- 配音基调（全体参考，具体逐角色看第二步音频卡）：______（如：整体语速偏快，爆发段升调）

## 六、禁忌与负向锚点

- 平台审核红线：______（如：无血腥、无亲密裸露、无吸烟特写）
- 负向提示词（constant negative prompt）：______（每项独立使用否定指令，如：`不要出现模糊画面；不要出现畸形手；不要出现额外手指；不要出现低清晰度；不要出现水印；不要出现文字。`）

条件性内容约束：剧本出现丧尸、亡灵、变异怪物、尸化角色、撕咬或近身伤害时，平台审核红线必须加入“非血腥表现”，并把以下固定词组逐项写入负向提示词：`不要出现血液；不要出现血迹；不要出现血浆；不要出现喷血；不要出现开放性伤口；不要出现裸露肌肉组织；不要出现裸露骨骼；不要出现肢解；不要出现断肢；不要出现断头；不要出现啃食人体；不要出现血腥恐怖特写。` 这些是条件性全剧约束，必须进入中文公共视觉词的负向段、`style.negative_prompt` 和 `style.taboos`。危险感改用灰败肤色、干枯质感、凹陷眼窝、僵硬动作、脏污破损服装和非血液污渍表达；不得在正向段使用伤口、腐烂创面、裸露组织或身体残缺作为造型细节。

## 产出：公共视觉词（调用输出）

压缩第零、三、六节：视觉路线 → 风格 → 色调光线 → 画质质感 → 负向约束。规则：

- 英文版正向部分 40–80 词；中文版正向部分以逗号分隔，使用 15–40 个稳定短语。负向部分单独放在末尾，以 `负向要求：` 开头；每个排除项都独立重复“不要出现……”或“禁止出现……”，并用分号隔开。
- 只写全剧不变的内容；不写任何具体人物、具体场景。
- **不含运镜**（运镜是逐镜动态，写第三步视频提示词段）、**不含配乐**（配乐归音频锚点与逐镜音频段）。
- **不含动态特效和界面层**：冰蓝数据光、发光能量、漂浮粒子、系统光屏、UI、HUD、血条、数据框、图标和文字都不进入公共视觉词。即使它们是全剧统一设计，也只记录在“动态特效/UI 基调”，按幕调用或后期叠加。
- 静态关键视觉元素只有在不会污染人物、场景和道具干净参考图时才能进入公共视觉词；具体实体仍放入一致性卡。
- 词根内**不写**单集情节变化，那是分镜提示词的变化段。
- 人物、场景和道具的具体描述只保存在第二步一致性卡中，不进入风格锚点。

## 组装方式

逐镜头提示词 = **公共视觉词 + 该镜头变化段**；人物、场景和道具事实从一致性卡引用。H3 目标按 [Prompt 契约](h3-prompt-contract.md) 组装正式字段，不直接拼接为无结构长段落。

## 校验清单（定稿前自查）

- [ ] 7 个维度全部填写（零~六），无空项
- [ ] 公共视觉词符合长度规则（英文正向部分 40–80 词 / 中文正向部分 15–40 个短语）
- [ ] 公共视觉词不含具体人物/场景；负向段以 `负向要求：` 开头，每个排除项都独立重复否定指令
- [ ] 公共视觉词不含动态光效、粒子、能量、UI、HUD、数据框、血条、光屏、图标或文字
- [ ] 默认路线已锁定为高精度3D写实国漫；未收到用户明确要求时没有切换真人
- [ ] 负向锚点与视觉路线互斥（默认3D明确禁止真人实拍/真人照片；只有用户明确要求真人时才禁止3D/卡通/动漫）
- [ ] 含丧尸、亡灵、变异怪物、尸化角色或近身伤害时，已启用完整“非血腥表现”固定词组，且正向段没有伤口、腐烂创面、裸露组织、断肢或内脏造型
- [ ] 词根不含任何单集情节

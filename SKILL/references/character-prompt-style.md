# 人物提示词编排器

本文件规定人物参考图提示词的写法。它解决的是“人物生成提示词写得像一张真正可用的角色设定图”，不改变分镜、运镜或 JSON 字段结构。

## 事实与审美分别处理

实体事实遵守 [生产协议](production-protocol.md) 的优先级：用户当前要求 → 剧本明确事实 → 已确认的一致性卡。人物卡是下游参考图的事实来源；预设不得覆盖姓名、外貌、服装、物种或剧情装备。

审美表达先采用用户当前指定的参考，再选用[已确认且适用的预设](character-style-presets.md)，最后使用全剧风格锚点。预设只提供段落组织、细节密度、材质和布光写法；没有适用预设时直接依据风格锚点设计，不强制套用 BJD。

Q版预设只借用材质、布光和细节密度，比例由 `chibi_design.head_body_ratio` 决定，不复制九头身、长腿或“大头娃娃”负向；具体分支见 [3D Q版内心戏](inner-theater.md)。

## 服装设计与定稿（创建人物卡时执行）

服装要形成有设计感、可辨识、能跨镜复现的角色造型。职业名称只是设计依据，不是完整服装方案；“蓝色工装、深色长裤、黑鞋”只交代品类，不能直接作为未指定造型的主角服装定稿。

### 已有设定与设计空间

- 用户、剧本明确指定的衣服类型、颜色、时代、身份限制，以及已确认的服装，优先于审美预设。明确要求朴素、制式制服或贫困装束时保留该要求，在合适的剪裁、搭配和材质上完成设计，不擅自换成华服。
- 剧本只给粗粒度描述时保留已知要素，设计其余结构；完全没写服装时，根据时代、职业、性格、行动需求与全剧审美主动提出一套完整造型，不默认套用最普通的日常服。普通美术补足无需另行询问，但不得改变人物阶层、阵营或剧情装备能力。
- 补足内容先写进人物卡 `outfit`，注明是本次美术设计而非原文事实，再生成参考图。卡片定稿后，参考图与分镜只能沿用；改造型先改卡片，不能在下游自行添饰。不得把具体身高、身份经历等未知事实当作服装设计空间。

### 从整体造型到可见细节

围绕角色选择相互协调的设计手段，不要求每个人堆满所有元素：

- **廓形与比例**：明确肩线、腰线、衣长和下装体积的关系，例如短外套与高腰宽裤、修长外袍与窄袖内层；不能只靠颜色区分人物。
- **穿搭层次**：说明内外层的露出关系、领口与袖口的呼应，以及鞋靴如何收住整套轮廓。适合单层衣服的角色可通过拼接、褶量或结构线建立层次，不强塞外套。
- **材质与工艺**：写出可见的软硬、哑光与微光、织纹与光滑表面对比，并落到具体部位；例如挺括主身配柔软袖片、细织内层配皮质镶边。用可建模细节表达质感，不用“高级、精致、华丽”替代设计。
- **配色与识别点**：主色、辅色和点缀色要有面积主次；为重要角色选择一两个稳定的造型识别点，如独特领型、偏置门襟、袖口织纹或特定扣具。写清位置、形状与材质，不靠大面积标志或发光装饰撑辨识度。
- **完整搭配**：从上装延伸到下装、鞋靴和合适的固定配饰，背面也有可复现的剪裁结构。装饰服从动作需求，不能让拖带、长摆或层叠首饰妨碍剧本中的检修、奔跑和打斗。

主角和重要配角应在廓形、层次、材质或设计识别点上形成区别；同职业角色保留制服体系，也要避免所有人只是同一件外套换颜色。群演可以更简洁。设计感不等于昂贵、暴露或装饰数量，不统一改成机能风、铠甲风或奢华礼服。

例如，未给具体造型的检修角色可以在保留工作服功能的基础上，设计短身立领外套、斜向门襟、肩肘同色耐磨拼片、窄幅织带点缀与立体膝褶裤装，再配结构清楚的工作靴。这说明如何把职业信息转成服装结构，不是其他职业或时代必须照搬的套装。

“干净常态”排除的是剧情灰尘、战损、临时装备和情绪，不排除原生纹样、刺绣、拼接、压线、饰边与固定配饰。“无品牌Logo”也不等于禁止原创装饰；装饰不能暗示未经设定的阵营或身份。保持三视图背景无场景、无文字即可，不要把人物服装一并简化成素面。

## 吸收用户样本的方法

收到用户的人物提示词样本时，先拆成五个可复用层，而不是概括成几个风格形容词：

- **审美层**：写实国漫/半写实国漫、BJD人偶感、东方甜美、清冷少年、偶像气质等。
- **建模层**：皮肤的白度和粗糙度、毛孔处理、CG五官结构、眼睛透明度、睫毛/卧蚕、鼻唇形状、发丝建模和服装面料。
- **比例层**：身高、头身比、肩腰腿关系、手脚大小，以及“严禁五五身、大头娃娃、短腿”等约束。
- **展示层**：固定三视图、纯白背景、均匀CG布光、85mm、f/2.0、Lookbook和8K级细节等资产展示条件。
- **排除层**：真人感、摄影感、比例压缩、服装材质、身份漂移、肢体错误、裁切、文字和水印等独立否定句。

生成当前角色时，五层都要有对应内容。若一致性卡缺少服装设计，先按“服装设计与定稿”补齐卡片；其他未知身份事实不能在参考图阶段凭空补写。若用户样本与当前角色卡的实体冲突，以当前角色卡为准，但保留样本的细节组织方式和表达密度。禁止把样本压缩为“高精度3D、BJD、白背景”三句套话。

## 人物提示词的九段结构

先判断资产是**人类单体**还是**非人单体生物**。两者共享高精度3D写实国漫、材质和质量标准，但展示逻辑不同：人类单体使用下方固定四视图锁定块；非人单体使用“单体生物全身设定图”分支，禁止把人类三视图、双手自然下垂或A-pose模板套到四足生物上。

如果角色卡的 `visual_variant` 为 `chibi`，先校验 `variant_of` 指向一个现实单体角色，再走独立的Q版分支：只生成一张透明或白底的完整Q版全身设定图，不套用人类四视图锁定块，不生成第二套现实身份。Q版必须从本体继承发型、服装主色和识别配饰，并在 `chibi_design` 中明确头身比、3D渲染质感、脸部表情语言、服装继承关系和动作语言；它只作为内心戏叠加层出现，不能被写成现实世界里的缩小人或让现实角色对其作出反应。

每个 `individual` 人类人物提示词都按以下顺序组织，不能压缩成“风格词 + 姓名 + 三视图 + 白背景”：

1. **媒介与审美**：默认使用高精度3D写实国漫；按角色气质补充半写实国漫、精致BJD人偶质感、CG角色建模、PBR材质和非真人摄影。只有用户明确指定其他路线时才切换，不能把真人摄影词写进3D正向段。
2. **体型与比例**：年龄段、性别、身高（只有卡片或用户明确提供时才写）、肩颈、肩宽、腰线、四肢、腿长、头身比例、手脚大小。没有精确数据时使用“比例协调、修长、自然”等定性词，不编造具体身高。
3. **皮肤与五官**：肤色和肌理（瓷肌、哑光、奶油肌、弱化毛孔等）、脸型、下颌、苹果肌、眼型、虹膜颜色和质感、睫毛、卧蚕、眼妆、鼻梁、鼻头、唇形和唇色。每项都要能被画面观察到。
4. **发型结构**：发色、长度、卷直、发量、颅顶、刘海、两侧发丝、发尾、分层、发丝光泽和材质。不能只写“黑色长发”或“帅气短发”。
5. **服装与配饰**：展开人物卡已经定稿的整套造型，先写廓形和穿搭层次，再写关键部位的材质、配色与识别点，最后写下装、鞋靴和固定配饰；不把设计压缩成衣服品类清单。剧情磨损留在镜头状态，原创设计默认不出现品牌Logo。
6. **身份状态**：基础图使用自然、平静、可复用的表情和站姿。剧情中的恐惧、愤怒、战损、投影、灰尘、账号牌、武器和其他临时物件放到分镜或道具卡。
7. **固定三视图构图**：严格使用本文件的“三视图锁定块”，不得改成其他布局。
8. **CG布光与渲染**：柔和面部主光、暖白侧逆轮廓光、CG发丝光、肩颈轮廓光、柔和接触阴影、85mm人像镜头氛围、f/2.0浅景深氛围、商业时装Lookbook级CG布光、8K级细节展示等词可以作为渲染层使用。它们描述CG资产的观感，不代表真人拍摄。
9. **角色专属负向**：先写比例、身份和解剖错误，再写媒介、服装和输出错误。每个排除项都单独使用“不要出现”或“严禁”，禁止只写一次“不要”后堆词。

### 人类提示词的去重与状态边界

- 每条提示词只允许出现一次人物身份块、一次服装块、一次固定构图块和一次负向块。不要先写一遍“姓名+外貌+服装”，再在风格段后重复同一组实体词。
- 推荐顺序是“媒介与渲染 → 人物身份/体型 → 皮肤与五官 → 发型 → 服装与配饰 → 基础状态边界 → 固定四视图锁定块 → CG布光 → 负向约束”。
- “人物身高和具体比例以一致性卡为准”不是可执行画面指令。若卡片没有精确身高，直接写“比例协调、修长、头身比例准确”；若卡片有身高，才写具体数值。
- 基础人物图只保留可复用的干净身份：灰尘、边缘磨损、账号牌、战刀、投影、系统界面、血条、情绪爆发和战斗姿态都属于镜头状态，不得混入基础身份段。

### 非人单体生物提示词分支

非人单体包括四足巨兽、龙、异兽、机械生物和大型变异生物。它们不使用人类固定三视图锁定块，也不写“人物三视图”“双手自然下垂”“人形A-pose”。参考图只承担**身份和结构锁定**，不承担视频中的城市规模、血月、云雾或剧情动作。

非人单体按以下顺序写成一条完整提示词：

1. **物种与媒介**：高精度3D写实国漫非人生物、电影级CG生物建模、PBR材质；先说明是动画CG资产，不是真人摄影。
2. **总体剪影**：体态（低伏/高肩/长躯/厚尾）、头身关系、背部宽度、四肢数量与承重方式、尾部走向。把“覆盖半座城市”这类视频尺度写入 `video_scale_anchor` 或镜头变化段，不写进白底身份图的正向主体描述。
3. **头部识别锚点**：头骨形状、吻部、下颌、眼睛形状与虹膜/瞳孔、角/冠/须/棘的位置。至少保留一个不可替换的视觉识别点，例如“狭长金色竖瞳”。
4. **躯干与表面材质**：颈部、肩胛、背甲、甲片分层、缝隙颜色、磨蚀纹理、反光强弱；写清“岩甲/鳞甲/金属装甲”属于哪一类结构，避免只写“很硬、很巨大”。
5. **四肢与尾部**：前后肢的粗细与关节方向、脚趾数量、爪形、承重姿态、尾根到尾端的变化。每个结构必须能在单体全身图中被看见。
6. **参考图构图**：单一画面、三分之四英雄角度或略低机位、完整全身、头尾和四足不裁切、剪影清晰、纯白无缝背景、均匀CG软光与接触阴影。
7. **非人专属负向**：排除人形化、卡通化、翼龙/蛇形误变体、额外肢体、畸形爪、身体裁切、城市或天气烘焙进白底参考图，以及真人摄影、文字和水印。

非人提示词必须同时生成一组短 `identity_lock`：`silhouette`（整体剪影）、`face_anchor`（头部/眼睛锚点）、`palette`（材质色区）、`signature_props`（角、棘、尾部等）、`immutable`（3–5条不可漂移特征），并可增加 `video_scale_anchor` 记录“在镜头里如何与楼群建立尺度关系”。

## 三视图锁定块（不可改动）

这是用户指定的三视图逻辑，必须原样保留：

> `16:9横版角色设定图；左侧为同一角色的大幅正脸半身特写，完整展示发型、五官、双耳、肩颈和上胸；右侧依次展示同一角色正面、标准侧面和背面全身；四个视图的身份、脸型、发型、皮肤/妆容、服装、配饰和鞋子完全一致；正面双手自然下垂，侧面自然端正站立，背面清晰展示发型与服装后部结构，鞋子完整入镜；纯白色背景，无渐变无杂色，均匀CG软光和柔和接触阴影，无场景、无剧情道具、无其他人物、无文字。`

不得做以下改写：

- 不得把“左侧特写 + 右侧三视图”改成中部三视图、四张独立图片或多张分开的提示词。
- 不得把正面双手自然下垂改成战斗姿态、抱物、插兜或夸张A-pose。
- 不得删除标准侧面、背面、完整鞋子或服装后部结构。
- 不得让特写和三视图出现不同脸型、发型、妆容、服装、配饰或比例。

非人四足生物、群体角色不套用这个锁定块：四足生物使用单体全身设定图；群体使用透明背景单画面群体图。只有用户明确要求非人角色也做三视图时才改用对应布局。

## 比例与媒介负向基线

人类角色根据适用性加入：

`不要出现与人物卡不符的头身比例；不要出现四肢长度漂移；不要出现解剖错误。` 身高、头身比与体型以人物卡为准；七头身、短腿或壮硕体型本身不是生成错误，只有与指定设计冲突时才排除。

男性角色按需要加入：

仅在人物卡与审美要求支持时排除油腻皮肤、塑料面料、胡须或不合设计的配饰。成熟、壮硕、有胡须的男性不得套用少年偶像负向；写实CG可保留适度皮肤纹理，BJD审美才按需要弱化毛孔，不把媒介负向等同于禁止材质细节。

女性角色按需要加入：

`不要出现真人感；不要出现夸张卡通化；不要出现油腻皮肤；不要出现廉价塑料面料；不要出现品牌Logo；不要出现头大身短。`

两类人物都可按实际需要加入：

`不要出现真人实拍；不要出现真人照片；不要出现写实摄影照片效果；不要出现人物不一致；不要出现视图顺序变化；不要出现肢体错误；不要出现畸形手；不要出现多余肢体；不要裁切鞋子；不要出现文字；不要出现水印。`

这些词只能排除错误，不能代替正向人物设计。3D角色不得在正向段写“真人摄影融合”或“真实照片质感”；可以写“细腻CG皮肤材质”“高级商业人像级CG布光”。

## 生成前后检查

生成前检查：

- 是否把用户示例的细节组织方式吸收进来，而不是只复制“BJD、3D、白背景”三个词？
- 是否写了皮肤、脸型、眼睛、鼻唇、发型结构、服装版型材质、比例和布光？
- 对未指定服装的主角，去掉“高级、精致”等形容词后，是否仍能画出有区别的廓形、层次和识别点？若只剩颜色与衣服品类，先重做人物卡的服装设计。
- 是否所有实体事实都来自当前人物卡，没有把示例角色的衣服和身高串给本剧角色？
- 是否保留三视图锁定块原文？

生成后检查：

- 人物提示词是否足够具体，删掉任意一个身份段都会不会造成脸、发型或服装无法复现？
- 负向词是否与正向设计冲突？
- 是否混入剧情动作、临时道具、投影、场景、HUD或动态光效？
- 同一角色在全剧所有镜头是否只引用这一张基础人物图？

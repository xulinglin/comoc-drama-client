# 用户确认的人物风格参考预设

这些预设来自用户提供的人物提示词样本，是人物参考图的**审美、细节密度、材质表达、布光和负向写法模板**。它们不是角色卡，不得把样本中的姓名、身高、衣服、帽子、包、首饰、建筑或时代设定自动移植到新角色。

## 事实与审美分别处理

实体事实遵守 [生产协议](production-protocol.md) 的优先级：用户当前要求 → 剧本明确事实 → 已确认的一致性卡。人物卡是下游参考图的事实来源；预设不得覆盖姓名、外貌、服装、物种或剧情装备。

审美表达先采用用户当前指定的参考，再选用已确认且适用的预设，最后使用全剧风格锚点。预设只提供段落组织、细节密度、材质和布光写法；没有适用预设时直接依据风格锚点设计，不强制套用 BJD。

Q版预设只借用材质、布光和细节密度，比例由 `chibi_design.head_body_ratio` 决定，不复制九头身、长腿或“大头娃娃”负向；具体分支见 [3D Q版内心戏](inner-theater.md)。

## 预设三：东方远古怪物 / 黑龙史诗

适用：东方玄幻、远古巨兽、黑龙、龙首压迫、云雾和古建筑等宏大非人角色。它不使用人类三视图锁定块；如果当前任务另有怪物三视图要求，才单独定义非人三视图。

```text
东方远古黑龙，体型遮天蔽日，巨大龙首逼近镜头，鳞片粗糙厚重，尖锐龙角与龙须翻扬，云雾翻涌，空中飞鸟四散，远景悬浮中式古楼阁，孤峭岩石。史诗压迫感，东方玄幻，电影级构图，8K，超精细细节，HDR，体积雾，暗调灰度画风。
```

这个预设的可复用结构是：**物种与体量 → 头部和轮廓 → 表面材质 → 动态姿态 → 天气/空间层次 → 远景地标 → 情绪与画质**。如果当前怪物属于末日废城、机械生物或其他世界观，只保留结构和细节密度，替换为当前世界的环境与材质；不得把中式古楼阁、云海或黑龙鳞片硬写进其他怪物。

### 非人巨兽身份图与视频尺度分离

非人巨兽的身份参考图只锁定可复用结构：物种、剪影、头部、眼睛、角/棘、甲壳分层、四肢、爪、尾部、色区和材质。它应是纯白或极浅中性背景的单体全身CG设定图，使用三分之四英雄角度，完整看见头、躯干、四足和尾部。不要在这张身份图里加入城市、楼群、血月、云雾、飞鸟或剧情攻击。

“体量覆盖半座城市”属于**视频尺度锚点**：在分镜中让楼群、街道和巨兽同框，用建筑作为比例参照；在身份锁中可写 `video_scale_anchor`，但不把建筑背景画进角色参考图。这样既能锁住怪兽长相，又能让 H3 在镜头里稳定表现压倒城市的尺度。

非人四足生物的可复用结构句式：**低伏宽背/肩部体块 → 短厚颈与楔形头 → 眼睛和角棘识别点 → 分层岩甲或鳞甲 → 粗壮前后肢与爪 → 粗根渐细的尾部 → 三分之四全身设定图**。每个结构都要写成可观察的形状、位置或材质，避免只堆“巨大、凶猛、史诗、压迫感”等抽象形容词。

## 与三视图逻辑的关系

甜美女性和清冷男性预设都只提供人物审美与内容密度。最终人物提示词必须在实体描述之后接入 [人物提示词编排器](character-prompt-style.md) 的固定三视图锁定块：左侧同一角色正脸半身特写，右侧正面/标准侧面/背面全身，正面双手自然下垂，侧面端正站立，背面和鞋子完整入镜。预设中的“四视图”不能被改成其他布局。

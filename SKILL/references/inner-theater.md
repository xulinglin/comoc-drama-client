# 3D Q版内心戏

当用户要求用3D Q版人物表现内心活动、吐槽、脑内推理或情绪具象化时读取本文件。它是可选分支，不改变普通现实戏和人物本体资产的默认写法。

## 资产关系

Q版人物是独立的 `CHAR-###` 人物资产，但必须通过 `visual_variant: "chibi"` 和 `variant_of: "CHAR-###"` 关联一个已存在的现实单体本体。Q版不替代本体，也不把本体的服装、脸型、发型和固定识别点重新发明一遍。

Q版人物卡仍使用 `individual / 1 / white / png`，参考图使用单一画面、完整全身的3D角色设定图，不套用现实人物的四视图规则。`chibi_design` 至少包含：

```json
{
  "head_body_ratio": "2.5头身",
  "rendering": "次世代UE5质感的3D动画渲染，细腻手办感CG材质",
  "face_style": "圆睁眉眼、简化但保留本体识别点",
  "costume_link": "继承本体服装的主色、廓形识别点和固定配饰",
  "pose_language": "夸张、活泼、清楚的重心变化"
}
```

Q版可以夸张头身比例、表情、动作和材质；不能新增本体没有的发色、制服、武器或阵营标识。Q版参考图的背景、光线和渲染可与本体不同，但角色身份必须可一眼对应。`head_body_ratio` 可写正数或“X头身”字符串。

## 现实层与叠加层

镜头增加 `inner_theater` 时，现实层仍按正常场景、机位和动作运行；Q版是叠加在画面中的观众可见形象。默认 `audience_only: true`：现实人物不看向Q版、不因Q版动作改变表演，也不发生物理接触。

```json
{
  "inner_theater": {
    "character_id": "CHAR-004",
    "anchor_character_id": "CHAR-002",
    "anchor_region": "霍焰头顶与左右肩头之间的可见叠加区",
    "height_in_anchor_heads": 0.28,
    "occlusion": "Q版脚部可被霍焰头发前缘短暂遮挡，身体不穿过头部",
    "lighting": "Q版使用独立暖色轮廓光，边缘与现实层分离但不发光过曝",
    "composition": {
      "safe_area": "锚点人物头顶与双肩之间，避开双眼、嘴部和关键道具",
      "max_frame_occupancy": 0.22,
      "occlusion_limit": "不得遮挡锚点人物双眼、嘴部和关键道具"
    },
    "audience_only": true,
    "pov_character": "CHAR-001"
  }
}
```

`character_id` 是Q版，`anchor_character_id` 是Q版当前依附的现实人物；二者可以不同。Q版本体的 `variant_of` 是它的心理拥有者，第一人称时应与 `pov_character` 一致。`anchor_region`、`height_in_anchor_heads`、`occlusion`、`lighting` 要让模型理解相对尺度和遮挡。镜头若用第一人称视角，`pov_character` 的现实脸部或完整现实表演不可直接展示；需要展示时切换到第三人称或让对白标记为 `offscreen`。

`composition.safe_area`、`max_frame_occupancy` 和 `occlusion_limit` 是画面安全边界：Q版可以在头顶与肩头之间运动，但不能遮住现实人物的眼睛、嘴部、关键道具或字幕区域。占比使用 0–1 的小数，建议 0.12–0.28；Q版越小，动作幅度越要靠姿态和表情而不是放大身体解决。

如果实际上传参考图，`references` 至少包含本体、现实锚点、场景和Q版；推荐 `reference_order` 按“第一人称本体 → 锚点人物 → 场景 → Q版 → 道具 → 音频”排列。这样 H3 的 `<Picture 1>`、`<Picture 2>` 等顺序与用户所说的“图1/图2/图3/图4”一致；未上传的资产仍写入文字事实，不伪造图片绑定。

## Q版动作与退场

每个有内心戏的 `acts[]` 都写一个 `inner_action`，即使本段只是停留，也写一个明确的保持动作。每个动作要有起点、路径、落点和收势：

```json
{
  "inner_action": {
    "from_anchor": "霍焰头顶中央",
    "to_anchor": "霍焰右肩上方",
    "motion": "连续两次轻快蹦跳，先屈膝蓄力，再向右肩落地，落地后双脚站稳",
    "expression": "眉眼圆睁、嘴角张开，震惊逐渐转为亢奋",
    "emotion_state": "震惊 → 亢奋",
    "gesture_beats": ["屈膝蓄力", "向右肩轻跳", "双脚落地站稳"],
    "follow_anchor": true
  }
}
```

`from_anchor` 与上一幕的 `to_anchor` 必须一致，不能瞬移。若内心戏结束，最后一段动作把 `to_anchor` 写成 `offscreen`，并在连续性账本中写同样的 `CHAR-###.overlay_anchor`；下一镜才可没有 `inner_theater`。若Q版跨素材持续，下一镜起点必须承接上一镜落点。

如果Q版离开后隔了几镜再次出现，第一段 `inner_action.from_anchor` 仍写 `offscreen`，再通过明确的跳入、飞入或落到锚点动作进入画面；不能直接从画外状态改成头顶或肩头状态。

每个 `inner_action` 还应写 `emotion_state` 和 `gesture_beats`，把“震惊 → 激动 → 思考”拆成可观察的表情与动作节点。`expression` 是最终表情状态，`gesture_beats` 是动作路径，不能只写“夸张表演”。

Q版表演包含面部变化，不能只有口型和手势。根据具体台词，在 `expression` 写出眉形、眼睑/视线、嘴角、头部姿态中至少两项可观察特征；`emotion_state` 写本幕起止情绪，例如“怀疑 → 错愕”，不写“随语意变化”。连续幕从上一幕的表情自然发展；无声停顿也可以保留思考、憋笑、迟疑等反应，不必立即回到中性脸。说话期间嘴形由口型驱动，嘴角与眉眼表达情绪，不能同时要求嘴唇紧闭或全程固定张大嘴。情绪稳定时允许保持，不为追求丰富而每幕换脸；Q版夸张不能改变本体身份识别点。

Q版内心戏不自动改变摄影机：固定镜头可以让Q版在锚点之间蹦跳；摄影机只有在现实层叙事需要时才移动。Q版运动必须说明与现实头肩的相对关系，不能让“跟随Q版”偷偷改变第一人称视线。

## 用户样本的镜头编排

用户常用的表现顺序可以保留，但要拆成可执行的现实层、叠加层和声音事件：

```text
画面叠加3D立体动漫Q版变小版（Q版角色），在（现实锚点人物）的头顶与肩头（锚点区域）来回蹦跳；眉眼圆睁、满脸震惊激动，肢体动作夸张活泼。
Q版人物以（内心语气）喊出台词：“（内心台词）”。停顿0.5秒后，（Q版角色）做出托腮/思考动作；若需要现实层继续说话，标记为现实声或画外声：“（第二句台词）”。
```

上面的自然语言只负责让导演读懂节奏，最终必须同时落成 `inner_action` 与带显式 `time` 的声音事件。第一人称镜头看不到本体的脸或完整身体，因此样本中的“本体做思考动作”应改写为Q版做思考动作，或把该镜头改为第三人称；不能一边声明第一人称又要求画面显示本体正面表演。

## 内心声、现实对白与停顿

Q版的心理归属由 `variant_of` 锁定，声音可以独立设计。默认兼容沿用本体声线；用户要求童声或独立Q版声线时，在Q版卡写 `inner_voice: {"mode": "dedicated", "audio_id": "AUDIO-003"}`，并新增 `character` 为Q版卡名称的音频卡，完整定义固定童声音色。沿用本体时写 `mode: "inherit"` 并引用本体音频卡；旧项目省略 `inner_voice` 仍按本体声线处理。不能把童声理解为新增现实儿童角色。

声音条目使用（下例为沿用本体；独立声线改为已声明的Q版音频ID）：

```json
{
  "type": "voice",
  "channel": "inner",
  "audio_id": "AUDIO-001",
  "lip_sync_target": "CHAR-004",
  "time": "00:00-00:04.50",
  "detail": "眼前这个人是我的死对头！他居然说他是我交往8年的男朋友！",
  "delivery": "亢奋、错愕，语速清楚",
  "pause_after_s": 0.5
}
```

`channel` 只能是 `inner` 或 `reality`。内心声引用 `inner_voice` 选定的 `audio_id`，并把该音频加入素材 `references`；口型只属于当前Q版。最终 Prompt 明确Q版开口、逐字说出台词并同步口型，本体在这句内心台词期间闭嘴，但可继续剧情所需的非语言表演。现实对白口型属于现实角色或 `offscreen`。第一人称人物的现实口型不可见时，不能把台词写成他正在镜头前张嘴。

## 出场节奏与可读性

- 按具体内心台词安排入场、说话表演、收势、退场。相邻内心句可连续保留；现实对白期间默认退场，只有明确的无声反应作用才保留，并逐幕写保持动作。不要把Q版永久挂在整段对话上。
- 入场和退场各有独立动作节拍；说话期间Q版可见，避免同一幕画外→入场→说话→退场→重入的往返。开始和结束均为 `offscreen` 的保持幕不安排Q版口型对白。
- Q版每句只选与语意相关的主要姿态变化；不把来回蹦跳套给所有句子。口型需要清楚时保持落点稳定，预留收势和停顿。
- 相对高度必须让嘴部可辨认；`0.28` 仅为示例，并非默认尺寸。按实际景别选择尺度和安全区，必要时调整现实机位，不能只有微小装饰性Q版却要求观众看清说话。
- 第三人称镜头不填 `pov_character`；心理拥有者由 `variant_of` 表示。仅真实主观机位才填写POV字段。
- 原稿仅有“旁白/内心独白”不等于用户要求Q版；选择本分支后保留原文，长句按自然语速拆素材，不增加吐槽台词。

每条内心声都明确 `time`，并且落在所属幕内；`pause_after_s` 是句后停顿，停顿期间可以继续表演但不能被另一句对白覆盖。配音按显式窗口的自然语速检查，放不下就拆分素材或重排，不用“亢奋语气”强行加速。画面文字仍写在 `visual`，不因为是系统信息或内心内容就自动朗读。

## H3编译与校验

编译器把内心层写进最终 H3 Prompt：现实层先描述，随后声明Q版叠加的锚点、尺度、遮挡和观众可见规则，再按时间顺序加入Q版动作与内心声。提示词中明确“不是缩小的实体人物”，避免模型让Q版与现实人物发生碰撞或改变空间物理。

质量门禁使用 `E025 INNER_THEATER` 检查资产关联、Q版设计、锚点连续性、叠加退出；使用 `E026 INNER_AUDIO` 检查声源归属、口型对象、时间窗口、停顿和自然语速。内心戏资产只锁定身份与表演媒介，不能把一条Q版动作复制到所有素材。

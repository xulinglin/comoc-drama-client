# 场景与道具设计定稿

创建或修改场景卡、道具卡及其参考图提示词时读取本文件。目标是让资产有明确设计、适合剧情动作、能跨镜复现；不能只写地点或物件名称，再附加“电影级、精细、8K”。

## 设计空间与事实边界

- 保留用户与剧本指定的时代、用途、形制、颜色、空间关系及已确认设计。未指定的造型、材质、结构细节可以主动补足，先写入对应一致性卡并注明是本次美术设计，再用于参考图和分镜。
- 补足不能新增改变剧情的出口、机关、功能、技术能力或阵营标识。关系剧情结果的数量、破损、连接与通行条件以剧本为准；普通美术选择不需要另行确认。
- 设计密度取决于剧情重要性和实际取景。主要场景、关键道具要能被认出；背景资产可以简洁。贫困、朴素、制式或空旷是有效设计要求，不自动升级成奢华、赛博、发光或复杂机械风。
- 全剧共享的材质与色彩倾向来自风格锚点；每个资产的具体实体设计只在卡片定义。新增美术细节不扩大正式资产种类，不增加布局图资产。

## 场景：先组织空间，再设计表面

场景卡应让另一位制作者能够复建一个有识别度的空间，而非一张泛用背景。根据用途组织以下内容：

- **主形体与比例**：说明空间是狭长、开阔、纵深、挑高还是低矮，墙体、柱列、屋顶与主要设施如何构成轮廓。尺度可借门、台阶、柜体等已有设施表达，不强造精确建筑尺寸。
- **区域与通行**：锁定入口、出口、操作区和主要地标的相对位置。先保证人物站位、开门、转身与道具操作能发生，再安排装饰；不能为构图把障碍物挪开，或增加剧本不存在的逃生路线。
- **视觉焦点与纵深**：为重要空间选择清楚的焦点及一两个识别地标，安排前景边界、中景动作区和远景终点。层次来自体块、明暗与遮挡关系，不靠堆放杂物；空旷场景可以用地面接缝、柱距与光区建立纵深。
- **材质分区与工艺**：明确地面、墙体、顶棚和固定设施的材质分工，落到接缝、边缘、厚度、支架、镶边或表面粗糙度。材质差异要在镜头尺度下可见，不能所有表面统一写成“灰色金属”或“精细石材”。
- **色彩与有来源的光**：主色、辅助材质与局部点缀有面积主次；基础光位来自明确的窗、灯具或环境方向。环境气氛不能让操作面、门槛和关键接口黑成一片，也不能每换一个机位就改变光源位置。
- **使用痕迹与时代感**：长期磨耗、修补接缝、设施更新的差异应有使用原因并稳定记录，避免随机铺满锈迹、裂纹和污渍。剧情中新发生的破坏、烟尘和灯光变化留给镜头状态。

将定稿分别落到 `environment`、`key_elements`、`landmarks`、`lighting_baseline`；短身份锁只保留不能漂移的空间或形体特征。换机位改变的是画面投影，地标的世界位置不变。

参考图按“CG媒介与用途 → 基准视角 → 主形体及空间分区 → 前中远景与地标 → 材质工艺 → 基础光位与色彩 → 动作留白 → 资产负向”写成完整提示词。整体用广角建立空间，但不要使用夸张鱼眼或过强景深遮掉结构。

“空场景”表示没有演员和临时剧情对象，不表示清空建筑细节与固定陈设。墙体原生纹样、地面拼缝、灯具、栏杆和固定设施可以保留；屏幕内容、站名等准确文字后期叠加，参考图保留其实体承载区域。

## 道具：外形要能解释用途

关键道具卡需要具体到能被拿起、放下、插入或开启，而不只是“一个金属盒子”：

- **轮廓与体量**：明确长宽厚的相对关系、边角、截面与最容易辨认的形状。手持物说明握持区域和相对手掌的尺度，大型物件说明其与既有设施的关系，不为所有物件强制编造毫米尺寸。
- **功能结构**：展开与剧情动作有关的接口、扣件、铰链、握柄或开合面；说明操作方向与可见接触位置。只表现剧本已有功能，不因“高级感”新增传感器、投影、武器或自动机构。
- **材质与制造细节**：明确主壳体、接触面、连接件和包覆材料的差异；选用适合用途的倒角、压线、铆接、嵌槽或织纹。细节要有结构原因，不能把每件道具都写成复杂装甲块。
- **色彩与识别点**：为关键道具选择稳定的局部特征，如偏置凹槽、特殊夹扣、固定缠带或特定边角。写清位置、方向和材料，普通物件也可辨识，不依赖文字、品牌或发光效果。
- **配合与同系列关系**：插卡与槽口、钥匙与锁等成对资产应共享相容的形制、厚度关系和插入方向。同系列设施可复用边框、扣件和材料语言，但不能以造型相似代替剧本未给出的功能兼容。

完整设计写入 `appearance`，简短不可变特征写入 `identity_lock`；持有、放置、插入、开合和损坏状态由连续性账本管理。与道具结构不可分的固定装饰可在基础图保留；姓名、倒计时、状态色等动态内容不烘焙进设计图。纯系统投影、UI、HUD不是实体道具。

参考图按“CG媒介与用途 → 整体轮廓和体量 → 功能部件及连接关系 → 材质工艺 → 识别点与固定配色 → 完整展示角度 → 资产负向”展开。使用单一画面、中性背景、完整物体，选择能同时看清轮廓与主要操作面的角度；浅浮雕或接口不能被高光淹没。默认一件道具一张图，不自动增加爆炸图、多宫格或多件变体。

## 设计复检

- 删掉质量形容词后，场景是否仍有可画出的空间关系、焦点和材质分区，道具是否仍有轮廓、操作面与识别点？若只剩品类，回到卡片补足。
- 设计是否服务剧本动作？接口能接合、门扇有活动空间、手持物有握持位置；取景能看见关键接触点。
- 同类资产是否有区别又属于同一世界？不把全部场景做成同一种大厅，也不把全部道具做成同一种发光金属盒。
- 参考图是否完整保留卡片定稿，且没有新增功能、提前显露剧情状态或改变既有关系？不合格时修订卡片并同步参考图与相关分镜。

这些是语义与视觉设计检查，JSON结构校验无法证明审美质量或真实成片可执行性。

# Python 本地服务迁移检查

检查日期：2026-10-03。范围为当前客户端调用的桌面 API、本地存储与 AI 生成链路，并对照原 Java 服务的接口契约。以下修复需保存当前任务、完全退出并重启客户端后生效；打包版需要重新构建分发。

## 已修复问题

| 功能 | 转换后的问题 | 修复结果 |
| --- | --- | --- |
| 图片生成与编辑 | 无论是否配置模型，均返回“未配置” | 读取已启用图片模型，转发生成或编辑请求，保存图片并返回本地预览地址 |
| MiniMax 音频 | `/ai/audio` 为占位报错 | 调用音色设计接口，检查业务错误，解码试听音频并保存为本地文件 |
| Seedance 视频 | 提交和查询接口均为占位报错 | 提交任务、查询状态、下载成片与尾帧，持久化已完成结果以复用查询 |
| 视频失败状态 | 前端未处理 `expired`；任务错误可能被当成查询连接失败 | 返回终止状态与任务错误，前端停止轮询并显示失败 |
| 文本转发 | `/ai/chat` 为占位报错，桌面请求层仅允许等待 30 秒 | 恢复非流式转发，支持完整 `/messages` 地址，等待时限与其他 AI 请求一致 |
| OriginalDoubao 账号持久化 | `/api/storage/data/account` 缺失，数据库读写失败后退回 JSON 缓存 | 补齐原始文档列表、读取、保存、删除及版本冲突响应 |
| 手动指定 OriginalDoubao 账号 | 未自动分配账号时，读取尚未定义的 `account` 变量 | 先读取指定账号，再锁定并提交任务 |
| 单个素材上传 | 忽略表单中的名称、描述、标签、类型、时长和关联项目 | 保存提交的字段及重复的项目关联字段 |
| 批量上传 | 接口直接返回空列表，不保存任何文件 | 逐项保存并返回实际素材记录；空上传返回错误 |
| 二进制上传 | multipart 解析删除文件首尾 CR/LF 字节 | 使用标准 MIME 解析器，保留原始文件字节 |
| 音视频预览与下载 | 下载整段读入内存，不支持 HEAD/Range，浏览器跨来源下载缺少响应头 | 支持分段读取、HEAD、Range、416 响应及浏览器读取文件 |
| 数据库连接 | SQLite 上下文仅提交事务，不关闭连接，Windows 可能持续占用数据库文件 | 每次存储事务结束显式关闭连接 |
| 每日额度 | 引用不存在的日期方法；同时扣减可能丢计数 | 修复日期判断、次日重置、每日上限及并发更新 |
| 共享提示词 | 切换“共享”仍返回全部提示词 | 按共享标记筛选，并应用数量上限；单机模式中“我的”包含本机创建的全部提示词 |
| 章节自动保存 | 切换章节或离开编辑器会取消尚未触发的保存；响应可能使用其他章节的当前文本 | 切换及离开时提交待保存草稿，按提交时的章节与文本快照保存，保留尚在保存中的草稿 |
| 存储设置和状态文案 | 保存目录后暗示立即生效；任务状态仍显示保存到 PostgreSQL 或服务器 | 明确目录修改需重启且不自动搬移数据，生成与保存状态改为本地 |

## 验证结果

- 38 项 Python 回归测试通过，使用临时存储及本机模拟模型服务。
- 章节切换、快速切回和退出编辑器的 1 项 Vue 源码回归测试通过。
- 原有存储冒烟测试、前端生产构建、Python 编译及 Git 差异检查通过。
- 当前前端调用的 44 个桌面 API 方法均存在。
- 对实际配置的存储目录做了只读核查：数据库含 8 个项目、6 个章节、44 个素材、11 个视频任务、6 个账号、10 个模型配置；547 条文件索引对应的二进制文件均存在。

检查及测试没有修改实际项目数据库、素材、账号或 API Key，未调用真实付费模型服务。

## 验证边界

- 真实供应商的余额、模型权限、网络、生成效果需在重启后实际生成验证；模拟测试不证明这些外部条件。
- OriginalDoubao 登录、网页生成、验证码及链接转换依赖现有登录态和网页结构；本次未执行网页生成或消耗 OriginalDoubao 额度。所需的内置 Chromium 文件已确认存在。
- MiniMax 当前恢复的是音色设计及试听文件，尚不等同于完整对白 TTS、口型同步或视频剪辑合成。
- 文本转发接口已恢复，但没有因此新增界面上的自动剧本创作流程。
- 修改项目存储目录不会搬移旧数据；客户端重启后使用所保存的目录。

实现依据为原 Java 服务及官方协议：[Seedance 提交任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Seedance 查询任务](https://api.volcengine.com/api-docs/view?action=GetContentsGenerationsTask&serviceCode=ark&version=2024-01-01)、[MiniMax 官方音色设计实现](https://github.com/MiniMax-AI/MiniMax-MCP/blob/main/minimax_mcp/server.py)、[Claude Messages API](https://platform.claude.com/docs/en/api/messages/create)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。

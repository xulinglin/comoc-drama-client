# 新手入门：从零开始生成你的第一条视频

[返回首页](../README.md)

这份文档写给**第一次使用 CDTV 的人**。跟着做，你就能从"打开软件"一路走到"生成出视频"。每一步都写清了要点击哪里、按钮叫什么。

> 说明：界面按钮文案以软件实际显示为准。如果你看到的文字和这里略有不同，说明版本有更新，按意思最接近的那个按钮操作即可。

---

## 〇、先搞清楚两件事（避免一开始就卡住）

**1. 这个软件本身不需要注册登录。**
打开即用，数据都存在你自己电脑上。

**2. 但"生成视频"需要你登录一个 OriginalDoubao 账号。**
软件是通过浏览器自动化，替你操作 OriginalDoubao 网页来生成视频的。所以你必须有一个 OriginalDoubao 账号，并在软件里登录一次。**没有登录账号，点生成会提示"暂无可用生成账号"。**

另外，软件**不会自动下载浏览器**。生成视频需要应用目录下存在内置浏览器文件：

```
你的安装目录/runtime/chrome-win64/chrome.exe
```

如果这个文件不存在，生成时会报"内置浏览器不存在"。打包版请确认分发时带了 `runtime` 目录。

---

## 一、启动软件

- **打包版**：双击 `CDTV.exe`。
- **源码版（开发者）**：双击根目录 `启动应用.bat`，或按 [开发指南](DEVELOPMENT.md) 运行。

第一次打开，会直接进入主界面，不需要登录。

> 小提示：如果软件打不开或白屏，多半是电脑缺少 **WebView2 Runtime**（Win10/11 一般自带）。见文末「常见问题」。

---

## 二、认识主界面

启动后，看**左侧边栏**，从上到下有几个入口：

| 位置 | 名称 | 用来做什么 |
|---|---|---|
| 左上 | **新建项目** | 快速新建一个项目 |
| 侧边栏 | **项目** | 管理剧本、章节、角色、场景、分镜进度 |
| 侧边栏 | **我的资产** | 集中管理图片、场景、音频、道具等素材 |
| 侧边栏 | **视频任务** | 快速单图生成视频的入口 |
| 侧边栏 | **图片生成** | 文生图与参考图编辑入口 |
| 侧边栏 | **链接转换** | 把视频分享链接转成无水印视频 |
| 左下 | **设置** | 账号中心、模型管理、运行设置 |

**新手的完整路线是这样的：**

```
设置里登录账号  →  建项目  →  建章节写剧本  →  建"视频创作任务"  →  准备素材  →  写分镜  →  点生成
```

下面一步步来。

---

## 三、（可选）先配好模型

如果你只打算用 **OriginalDoubao** 生成（走浏览器自动化），可以跳过这一步，直接去第四节登录账号。

如果你想用接口方式生成图片 / 视频 / 音频（例如 Seedance、MiniMax），先到 **设置 → 模型管理** 里 **添加模型**，填好：

| 字段 | 说明 |
|---|---|
| 类型 | 必填，文本 / 图片 / 视频 / 音频 |
| 显示名称 | 必填，例如 `Seedance-2.0-fast` |
| 供应商 | 必填，例如 `Seedance` |
| 模型名（API 参数） | 必填，**必须和服务商给的完全一致** |
| API 地址 | 必填，服务商提供的接口地址 |
| API Key | 填你自己申请到的 Key |
| 排序 / 启用 | **要勾选"启用"才会在生成页面出现** |

> ⚠️ 两个易踩的坑：
> - **编辑已有模型时，API Key 留空 = 保留原来的 Key**，不会被清空。
> - **模型必须勾选"启用"**，否则生成页面里选不到它。

---

## 四、登录 OriginalDoubao 账号（生成视频必做）

1. 点左下角 **设置**，打开「设置中心」。
2. 切到 **账号中心** 标签（小字：生成账号与额度）。
3. 在输入框里输入一个账号名（例如"主账号"），点 **添加账号**。提示"已创建 XXX"即成功。
4. **选中**刚添加的账号，点 **登录所选账号**。
5. 会弹出一个浏览器窗口，在里面**手动完成登录**（输账号密码 / 扫码）。
6. 登录完成后**关闭浏览器窗口**。回到软件，账号状态会变成已登录（已登录时按钮会变成 **打开所选账号**）。

**Dola 账号登录：**

1. 添加账号时选择 **Dola**，选中账号后点击 **登录所选账号**。
2. 软件优先使用本机安装的 Google Chrome，为该账号打开专用登录窗口；未安装时尝试内置浏览器。
3. 在 Dola 网页中手动登录，然后回到软件点击 **完成登录**。如果已经手动关闭浏览器，仍需点击此按钮。
4. 软件关闭专用窗口并校验登录，成功后显示 **Dola 登录成功，登录状态已保存**。

账号登录待确认时不能启动该账号的生成任务。首次打开的专用窗口需要单独登录；后续生成会复用该账号的登录状态。

**额度说明：**
- 每个账号有每日生成次数上限，默认 **3 次/天**（这是软件的设置，不代表平台真实额度）。可在 **账号中心** 顶部用 `单账号上限` 的 `+` / `-` 调整。
- 生成成功后自动扣减，第二天重新计数。
- 账号生成时会进入"运行中"锁定，用完自动释放。

---

## 五、创建项目

**项目是最大的容器**，素材和任务都挂在项目下。

1. 点侧边栏 **项目**（或左上角 **新建项目**）。
2. 点页面里的 **新建项目** 按钮。
3. 弹窗里填：
   - **项目名称**（必填，例如"末日重生"）
   - **项目简介**（选填）
   - **风格**：从「3D国漫 / 真人写实 / 二次元 / Q版」里选一组
   - **视频比例**：`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`
4. 保存。项目卡片就出现在列表里了。

---

## 六、进入项目、写剧本章节

1. 在项目列表里点进你的项目，进入项目详情。
2. 右侧「章节目录」面板右上角，点 **+**（新增章节）。
   > 注意：点 `+` **会直接新建一个标题为「新章节」的章节**，没有弹窗，也不会问你标题。
3. 选中章节，在下方的 **原文** 输入框里粘贴或输入你的剧本内容。
   面板上有 `文本` / `预览` 两个视图切换，右上角会显示 `保存中…` / `✓ 已保存`。
   > 内容是自动保存的，不用手动点保存。

到这一步，剧本就有了。接下来去做分镜和生成。

---

## 七、创建"视频创作任务"

**视频创作任务才是真正生成视频的地方**，它必须归属一个项目。

1. 进入 **视频任务** 相关区域，找到 **视频创作任务** 列表。
2. 点 **新建任务**。
3. 弹窗里填：
   - **任务名称**（例如"末日 Online"）
   - **关联项目**（必选，选你刚建的项目；如果下拉是空的，说明还没建项目，先回上一步）
   - **任务描述**（选填）
4. 点 **创建并进入工作台**。

> 如果提示"暂无项目，请先创建项目"，就是你还没建项目，回到第五节先建一个。

---

## 八、准备素材（人物 / 场景 / 道具 / 白模 / 音频）

进入工作台后，**左侧是「资产数据」面板**，就是放素材的地方。

### 方式 A：导入创作数据 JSON（推荐，一次全导入）

1. 在「资产数据」面板右上方，点 **操作** 按钮（三个点图标）。
2. 点 **导入创作数据 JSON**。
3. 弹窗里可以：
   - 直接**粘贴 JSON 文本**，或
   - 点 **选择 JSON 文件** 从电脑里选 `.json` 文件。
4. 点 **解析并导入**。

导入成功后，会显示类似 `项目名 · v版本 · N 项资产 · M 个分镜` 的摘要。

> 想先拿一份现成样例练手，可以用仓库自带的
> [`SKILL/test-json/末日重生-完整数据.json`](../SKILL/test-json/%E6%9C%AB%E6%97%A5%E9%87%8D%E7%94%9F-%E5%AE%8C%E6%95%B4%E6%95%B0%E6%8D%AE.json)。
> 它包含人物、场景、道具、音频和 18 条分镜，可直接导入。

导入能识别的字段包括：人物（`characters`/`roles`）、场景（`scenes`）、道具（`props`/`items`）、白模（`layouts`）、音频（`audio`）、提示词（`reference_prompts`）、分镜（`shots`）等。

### 方式 B：手动准备素材

- 面板上方有分类标签：**全部 / 人物 / 场景 / 道具 / 白模 / 音频**，点击切换查看。
- 没有图片的素材，卡片上会有 **生成图片**（音频则为 **生成音频**）按钮，点一下用图片模型生成。
- 想一次全生成，可用操作菜单里的 **一键生成全部**（会自动跳过已经生成好的）。

### 生成素材图片需要先选图片模型

在「操作」菜单里有一项 **图片生成模型**，先在这里选好你要用的图片模型，才能生成素材图。

---

## 九、写分镜、加参考图

工作台**中间是「分镜」区**。

1. 点右上角 **新增分镜**，添加一条分镜（也可以由第八节的 JSON 一次导入）。
2. 每条分镜里：
   - 顶部可填 **分镜名称**。
   - **参考图**：点 **本地上传** 从电脑传图片/音频；或回到左侧素材卡片点 **添加到分镜**。
   - **提示词**：在输入框里描述这一镜的画面。输入 `@` 可以**引用已上传的素材**。
3. 想看实际会发给引擎的完整内容，可以点编辑框上的"查看实际发送内容"。

---

## 十、设置参数并生成视频

在每条分镜的底部工具栏：

1. **选模式**：点模式按钮，选
   - **参考生成**：用你上传的参考图生成。
   - **首尾帧**：指定首帧和尾帧。
2. **点参数摘要按钮**（显示类似 `OriginalDoubao · 16:9 · 720P · 10秒 · 静音 · 1条`），展开设置面板，可调：
   - **生成模型**：`OriginalDoubao`（走浏览器，标记 WEB）或 `Seedance`（走接口，标记 API）。
   - **视频比例**：`21:9` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `智能`
   - **分辨率**：`480P` / `720P` / `1080P` / `4K`
   - **输出声音**：开 / 关
   - **视频时长**：`按秒数`（1–15 秒）或 `智能时长`
   - **生成数量**：1–8 条
3. 点分镜右下角的 **生成视频** 按钮。

> **用 OriginalDoubao 时的两个限制（正常现象）：**
> - 时长和生成数量**不可调**，会固定走智能时长、1 条。
> - 生成过程中，**需要你切到弹出的浏览器里手动点一下确认**，软件没法替你点这个。

---

## 十一、查看进度和结果

分镜下方的**结果区**：

- 生成中：显示 `正在生成视频` 和进度百分比。
  - OriginalDoubao 会提示"请切换到 OriginalDoubao 浏览器手动点击确认"。
- 失败：显示 `生成未完成`，可点 **重新生成**，或点 **上传本地视频** 用本地文件替换。
- 完成：显示 `视频生成完成`，可以直接在分镜里**播放**，也可以 **下载当前视频**、**放大播放**。

**视频存在哪？**
默认保存在 **视频输出目录**（一般是软件目录下的 `output/`）。
- 在 **设置 → 运行设置** 里能看到「视频输出目录」，还能点 **打开** 直接打开文件夹。
- 那里还可以勾选 **自动下载结果**（任务完成后自动保存到输出目录）。

---

## 十二、运行设置（了解即可）

**设置 → 运行设置** 里可配置 **默认账号**、**视频输出目录**、**项目存储目录**、**自动下载结果**。

> ⚠️ 修改 **项目存储目录** 后**需重启软件才生效**，且**不会自动搬运旧数据**。要保住旧数据，先关软件，手动把原目录整个复制到新位置。

## 十三、给新手的常见卡点速查

| 现象 | 原因 / 解决 |
|---|---|
| 打开软件白屏或打不开 | 电脑缺 WebView2 Runtime，装一个即可 |
| 点生成提示"暂无可用生成账号" | 还没在 设置 → 账号中心 添加并登录 OriginalDoubao 账号 |
| 生成报"内置浏览器不存在" | 缺 `runtime/chrome-win64/chrome.exe`，确认安装目录里这个文件在 |
| 生成页里选不到我加的模型 | 模型没勾选"启用"；或 API 地址 / 模型名填错 |
| 改了 API Key 反而失效 | 编辑模型时 Key 留空表示"保留原 Key"，别故意清空 |
| 找不到登录/注册页 | 软件本来就免登录，直接进主界面，别去找登录页 |
| 新建任务建不了 | 必须先有项目；任务"关联项目"是必填的 |
| 新建章节没有弹窗 | 正常，点 `+` 直接生成标题为"新章节"的章节 |
| 改了设置没生效 | 改存储目录、改 Python 代码都需**完全重启**软件才生效 |
| OriginalDoubao 生成卡住 | 需要你切到浏览器窗口手动点确认 |
